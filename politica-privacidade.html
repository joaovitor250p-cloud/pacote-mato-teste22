Política de Privacidade - Pacote É Mato

Última atualização: Setembro de 2026

O aplicativo Pacote É Mato respeita a privacidade dos seus usuários e está comprometido em proteger as informações coletadas durante o uso do aplicativo.

1. Informações coletadas

Para oferecer as funcionalidades do aplicativo, podemos coletar algumas informações fornecidas pelo usuário, como:

  • Nome ou identificação informada pelo usuário;
  • Informações necessárias para criação e utilização da conta;
  • Dados utilizados para funcionamento das ferramentas do aplicativo;
  • Informações técnicas necessárias para melhorar o funcionamento do aplicativo.

2. Uso das informações

As informações coletadas são utilizadas exclusivamente para:

  • Permitir o funcionamento das funcionalidades do aplicativo;
  • Melhorar a experiência do usuário;
  • Corrigir erros e melhorar a segurança;
  • Manter e aprimorar os serviços oferecidos.

3. Armazenamento dos dados

Algumas informações podem ser armazenadas utilizando serviços de terceiros, como plataformas de armazenamento em nuvem, para garantir o funcionamento adequado do aplicativo.

O aplicativo utiliza serviços de tecnologia como Firebase para armazenamento e gerenciamento de dados necessários ao funcionamento das funcionalidades.

4. Compartilhamento de informações

Não vendemos, comercializamos ou compartilhamos informações pessoais dos usuários com terceiros para fins publicitários.

Os dados poderão ser compartilhados somente quando necessário para:

  • Cumprimento de obrigações legais;
  • Proteção contra fraudes ou uso indevido;
  • Manutenção dos serviços utilizados pelo aplicativo.

5. Segurança

Adotamos medidas técnicas para proteger as informações dos usuários contra acesso não autorizado, alteração ou divulgação indevida.

Apesar disso, nenhum método de armazenamento eletrônico é totalmente seguro, portanto não podemos garantir segurança absoluta dos dados.

6. Serviços de terceiros

O aplicativo pode utilizar serviços externos necessários para seu funcionamento, como ferramentas de análise, armazenamento e processamento de informações.

Esses serviços possuem suas próprias políticas de privacidade.
